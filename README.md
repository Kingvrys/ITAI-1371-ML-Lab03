## 📌 Project Overview
This repository contains the completed deliverables for the Module 03 Lab. The project explores the complete machine learning workflow—spanning data preparation, feature selection, data splitting, model training, evaluation, and interpretation—while comparing Supervised (Classification/Regression), Unsupervised, and Reinforcement Learning paradigms using the Wine dataset.
